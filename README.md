# Nudge

A mobile-first frontend prototype for a friendly social reminder app.

## Prototype features
- **For me** and **Sent by me** views
- Create and schedule a simulated nudge
- Ready, upcoming and acknowledged states
- Got it / Done interactions
- WhatsApp handoff
- Activity and profile screens
- No backend yet; demo data resets on refresh

## Next phase
Firebase authentication, Firestore sync, scheduled notifications and official WhatsApp integration.
